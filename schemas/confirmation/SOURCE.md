# FpML schema source

The checked-in Confirmation View XSDs and product example XMLs are from the public
5.12 mirror at <https://github.com/matsuuramasakazu/fpml_workspace>, commit
`8a7aacf2378308bf67d511a0baf70db9bed3e697` (shallow checkout, 2026-10-19).
The mirror includes only the 5.12 confirmation view; no 5.13 confirmation source
was available there. The XSDs and examples identify themselves as FpML and carry
the FpML public-license notice. See the included `LICENSE-FPML` (version 3.0,
effective 2026-02-01) for the terms governing those specifications. The mirror's
repository MIT license applies to its software and is not substituted for the
FpML specification license.

FpML and ISDA marks identify the specification only. This Rust project is an
independent implementation and is not endorsed by ISDA.
